# Metrics

## Product/source-code metrics

Initial Python metrics:
- LOC: lines of code reported by the selected metric tool.
- Cyclomatic complexity: control-flow complexity.
- Function count.
- Class count.

## Process/repository metrics

Initial file-level metrics:
- Commit count.
- Distinct author count.
- Lines added.
- Lines deleted.
- Churn = lines added + lines deleted.
- First and latest observed commit timestamps.
- File age where sufficient history exists.

## Research caution

Metrics are predictive features, not proof of defect presence. Tool definitions and
measurement conventions must be documented so experiments remain reproducible.
